# Test HTML Website

This is a minimal static website for testing the Website Manager flow.

## Files

- `index.html`
- `about.html`
- `styles.css`

## Suggested config in your dashboard

- Framework: `Static HTML`
- Install command: `echo "No install required for static HTML."`
- Build command: `echo "No build required for static HTML."`
- Start command: `npx serve -s . -l 3000`

## Push to GitHub

Run from this directory:

```bash
git init
git add .
git commit -m "Initial static HTML test site"
git branch -M main
git remote add origin <YOUR_GITHUB_REPO_URL>
git push -u origin main
```
